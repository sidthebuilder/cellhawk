1. Architecture: The Dual-Head Oracle

Unlike standard rigid classifiers, NEXUS-7 utilizes a Dual-Head Temporal Transformer. This architecture allows for simultaneous supervised classification and unsupervised anomaly detection on a single inference pass.

1.1 Zero-Day Anomaly Autoencoder

The system calculates an anomaly score by comparing the input radar embedding to its unsupervised reconstruction. A spike in MSE (Mean Squared Error) indicates a target with a never-before-seen radar signature.

# Deep Anomaly Scoring Logic

2. Optimization & Quantization Strategy

To achieve sub-5ms latency on Low-SWaP (Size, Weight, and Power) hardware like the NVIDIA Jetson Orin Nano, the system implements a multi-tier optimization pipeline.

APPENDIX A: Optimization Benchmarks
  • TensorRT INT8: 4.2ms inference latency (Quantized with static calibration).
  • TensorRT FP16: 6.8ms inference latency (Production baseline).
  • OpenVINO IR: 12.4ms (Intel Myriad fallback).
  • ONNX Runtime: 45ms (CPU-only validation mode).

2.2 Precision Management

The EdgeOptimizer module auto-detects the hardware backend and selects the optimal precision mode (INT8 vs. FP16) based on the target platform's fast-math capabilities.

# Hardware-Aware Precision Selection
if TRT_PRECISION == "fp16" and builder.platform_has_fast_fp16:
    config.set_flag(trt.BuilderFlag.FP16)
elif TRT_PRECISION == "int8" and builder.platform_has_fast_int8:
    config.set_flag(trt.BuilderFlag.INT8)
